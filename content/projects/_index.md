Projects are central to CodeWeekend's teaching model: learners apply each new skill in real assignments, build portfolio work, and present capstones at Demo Day.

These projects were published in the 2026 cohort update. The former site's project buttons did not contain working demo URLs, so this archive preserves the original showcases without linking visitors to broken destinations.
